*[BOOTSEL]: Boot select: the button that starts the board as a USB drive for flashing
*[CDC]: Communications Device Class: the USB class that makes the board look like a serial port
*[CYW43]: Infineon CYW43439, the Wi-Fi and Bluetooth chip on the Pico 2 W
*[DMA]: Direct Memory Access: hardware that copies data without the CPU
*[GPIO]: General-Purpose Input/Output: a pin the program can read or drive
*[I²S]: Inter-IC Sound: a serial bus for digital audio
*[PIO]: Programmable I/O: small state machines in the RP2350 that run their own tiny programs
*[PTT]: Push-to-talk
*[SDK]: Software Development Kit
*[UF2]: USB Flashing Format: a file you drag onto the board to program it
