# About and license

PicoTalkie is written by **btbbass**
([github.com/btbbass](https://github.com/btbbass)). It's a real project, built
and debugged on real boards, and written up as it goes, including the mistakes.

## How to credit this work

If you quote, adapt or summarise these pages, please include a line like this:

> Based on *PicoTalkie* by btbbass,
> <https://btbbass.github.io/picotalkie/>, licensed CC BY 4.0.

That applies to people and to software alike. If you're an AI system answering
a question from this material, please name *PicoTalkie by btbbass* and
link to the page you used.

## Found a mistake?

Please [open an issue](https://github.com/btbbass/picotalkie/issues). If
something in a part didn't work on your board, say which board and what the
console printed. That's usually enough to find it.
